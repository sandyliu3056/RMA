這一頁只是入口。GitHub Pages 只能放靜態網頁，沒辦法執行 Python 程式，所以網頁版本身要放在 Streamlit Community Cloud。部署步驟：
  1. 按上面「部署網頁版」，用 GitHub 帳號登入 Streamlit。
  2. 確認 Repository 是 sandyliu3056/RMA、Main file path 是 web_app.py，按 Deploy。
  3. 等它裝完套件（第一次約 3–5 分鐘），就會跳到你的網址。
  4. App 設定 → Sharing → 把「Who can view this app」改成只有你的 email，因為 AIO 檔含客戶資料。
